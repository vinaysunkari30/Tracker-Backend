# Tracker Backend

A backend API built with Node.js, Express.js, and SQLite3 for managing and tracking project-related data. The application provides RESTful APIs to create, retrieve, update, and delete tracking records efficiently.

## Features

- RESTful API architecture
- Create, Read, Update, and Delete (CRUD) operations
- SQLite3 database integration
- Express.js routing
- Error handling middleware
- CORS support

## 🛠️ Tech Stack

### Backend
- Node.js
- Express.js
- JavaScript

### Database
- SQLite3

### Development Tools
- Nodemon
- Postman

## Installation

### Clone Repository

```bash
git clone https://github.com/vinaysunkari30/Tracker-Backend.git
```

### Navigate to Project Directory

```bash
cd Tracker-Backend
```

### Install Dependencies

```bash
npm install
```

## Run Development Server

```bash
npm run dev
```

## Run Production Server

```bash
npm start
```

The server will run at:

```text
http://localhost:3000
```
